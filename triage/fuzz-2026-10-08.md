- **Crash, `table.rb:241` `Cell#initialize`: undefined method `sourcemap`
  for nil** (2.0.26 and main; Ptome converts it). 311 hits.

  ```asciidoc
  [%header,cols="s,~,>"]

  ```

- **Crash, `docbook5.rb:611` `convert_inline_quoted`** (found by the first
  campaign; not in this top 25).

- **Duplicate inline anchors are not reported**: `anchor:_ak[]` twice gives
  two `id="_ak"` without a warning (both implementations).

## Ptome differs from Asciidoctor main (fix or port bug? check PARITY.md)

| Input | Asciidoctor main | Ptome |
|---|---|---|
| `[verse]` then `== Title` | `<verse xml:id=…>` | `<section>` |
| `[partintro]` then `== Title` | `<partintro xml:id=…>` | `<section>` |
| `[#open.example][#y]` then `[abstract]` `--` block | `<abstract>` (the first line is an attribute line) | `<simpara>[#open.example][#y]</simpara>` |
| paragraph, `[quote]`, `+` | `quoteblock` | `paragraph` |
| ``= `title` text [[_id]]`` with `:showtitle:` | `<h1 id="_id">` | `<h1>` (no id) |
| `==== Title 1 .1.2` | `<title>Title 1 .1.2</title>` | `<title>Title 1</title>` |

## Known, intended Ptome divergences seen

- Man page font restore (`\fP` vs `\fI…\fR`): asciidoctor#4875.
- ``== `'`` gets `id="_"`, not `id=""`: asciidoctor#4877.
- `<phrase role=…>` instead of `<emphasis>` inside `<literal>` (DocBook validity).

## Oracle false positives fixed after this run

- groff needs `-k` (UTF-8 input) and only whole man pages are checked
  (embedded ones lack the `MTO`/`URL` macro definitions).
- Embedded HTML leaves the document title out, so its words aren't tracked.
