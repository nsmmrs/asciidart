== Name

asciidart - convert AsciiDoc documents to HTML, DocBook and man pages

== Synopsis

*asciidart* [_OPTION_]... _FILE_...

*asciidart init-config* [_DIR_] [*-f*]

== Description

*asciidart* reads each AsciiDoc _FILE_ and writes the converted document next to it, under the same name with the extension of the output format (for example, _guide.adoc_ becomes _guide.html_).
A _FILE_ of *-* reads the document from standard input and writes the result to standard output.
Arguments may be glob patterns (`+*+`, `+?+`, `+[...]+` and `+**+`), which *asciidart* expands itself.

*asciidart* is a re-implementation of Asciidoctor in Dart.
It accepts the same documents, attributes and options as the *asciidoctor* command of Asciidoctor {asciidoctor-version} and produces the same output, except for the deliberate differences listed in the project's documentation.

Messages about the document (warnings, errors) go to standard error.

== Options

=== Output

*-b, --backend*=_BACKEND_::
  The output format: *html5* (the default), *xhtml5*, *docbook5*, *manpage*, *epub3*, *pdf* or *multipage_html5*.
  *epub3* writes an EPUB 3 file (as asciidoctor-epub3 does), so it needs an output file rather than standard output; it is available in the native executable, not in the npm package.
  *pdf* writes a PDF file with asciidart's own layout, reading asciidoctor-pdf's YAML themes (*pdf-theme*, *pdf-themesdir*, *pdf-fontsdir*); justified text is hyphenated in the document's language (*-a hyphens!* turns it off). Set the *pdf-compat* attribute (*-a pdf-compat*) to lay the document out as asciidoctor-pdf 2.3.27 does. Like *epub3*, it needs an output file and the native executable.
  *multipage_html5* writes a website: the output file is the home page (the header, the preamble and a list of the pages), and each part and chapter (each section up to *multipage-level*) is a page of its own beside it, named after its id (or its *page-path* attribute: *page-path=part/one/* writes *part/one/index.html*), with links to the previous, enclosing and next pages; links reach across pages. *multipage-toclevels* lists each page's sections on the home page down to that level. Like *epub3*, it needs an output file and the native executable.

*-d, --doctype*=_DOCTYPE_::
  How to interpret the document's structure: *article* (the default), *book*, *manpage* or *inline*.

*-e, --embedded*::
  Write only the converted body, without the surrounding page (for HTML: no _<html>_, _<head>_ or footer).
  Useful for inserting the result into another page.

*-s, --no-header-footer*::
  The same as *-e*.

*-o, --out-file*=_FILE_::
  Write the output to _FILE_ instead of the derived name.
  Use *-* to write to standard output.

*-D, --destination-dir*=_DIR_::
  Write output files to _DIR_.
  Combined with *-R*, the input's folder structure below the source directory is recreated below _DIR_.

*-R, --source-dir*=_DIR_::
  The root of the input files, used with *-D* to compute where each output file goes.

*-n, --section-numbers*::
  Number the section titles.
  The same as *-a sectnums*.

=== Document attributes

*-a, --attribute*=_NAME_[=_VALUE_]::
  Set the document attribute _NAME_, overriding any value the document assigns.
  _NAME_ alone sets it to an empty value; _NAME_*!* unsets it.
  End the name or the value with *@* (_NAME_@=_VALUE_ or _NAME_=_VALUE_@) to let the document override it instead.
  May be given more than once.

=== Safety

*-S, --safe-mode*=_MODE_::
  How much the document may reach outside itself: *unsafe* (the default for this command), *safe*, *server* or *secure*.
  The stricter modes restrict include directives, file access outside the base directory and remote content.

*--safe*::
  The same as *-S safe*.

*-B, --base-dir*=_DIR_::
  The directory that relative paths in the document (includes, images) are resolved from.
  The default is the input file's directory, or the working directory for standard input.

=== Custom converters

*-T, --template-dir*=_DIR_::
  Override how individual elements are converted with the Mustache templates in _DIR_.
  May be given more than once; later directories take precedence.

*-E, --template-engine*=_NAME_::
  The template engine for *-T*: *mustache*, or *dart* for converter functions compiled into a custom binary (see *Custom binaries*).
  Any other name fails once templates are in use.

=== Messages

*--failure-level*=_LEVEL_::
  Exit with status 1 when a message of _LEVEL_ or higher is logged: *INFO*, *WARN*, *ERROR* or *FATAL* (the default).

*-q, --quiet*::
  Print no messages about the document.

*-v, --verbose*::
  Also print messages at the *DEBUG* and *INFO* levels.

*--trace*::
  On an unexpected error, print the full stack trace.

*-t, --timings*::
  Print how long reading, parsing and converting each file took.

*--progress*::
  Report each phase of a conversion (reading, parsing, converting, writing) as it finishes, with its time.
  With *-v*, the PDF backend also reports how many pages it laid out.

=== Cores

*-j, --jobs* _N_::
  Convert several input files at once, on _N_ workers; the output files, the messages and the exit status are those of converting them one after another.
  Each file is then converted on one core.
  Within one document, the PDF and EPUB backends use the machine's physical cores for the work that doesn't depend on order (images, compression) and keep the output the same, byte for byte; **-a jobs=**__N__ sets how many (*1* for none).

=== Information

*-h, --help* [_TOPIC_]::
  Print the option summary.
  With _TOPIC_ *syntax*, print an overview of the AsciiDoc syntax; with *manpage*, print this manual page as troff source (view it with *asciidart -h manpage | man -l -*).

*-V, --version*::
  Print the version of *asciidart*, the Asciidoctor release it is compatible with, and the runtime.
  *-v* does the same when it is the only argument.

== Custom binaries

*asciidart init-config* [_DIR_] creates a small Dart project in _DIR_ (the working directory by default) whose program registers Dart functions as converters and then runs this command line.
Compile it with *dart compile exe* to get a custom *asciidart* with those conversions built in.
*-f* overwrites existing files.

== Environment

*SOURCE_DATE_EPOCH*::
  When set to an integer number of seconds since the Unix epoch, it replaces the current time and the input files' modification times in the document's date attributes, for reproducible output.

*ASCIIDART_COMPAT*::
  The default of the *asciidoctor-compat* attribute: *true*, *false*, or a comma-separated list of formats (*html*, *epub*, *docbook*, *manpage*, *pdf*) whose output keeps Asciidoctor's look.
  Without it, *compat:* in the nearest *asciidart.yml* in the input's directory or one above it, then in *$XDG_CONFIG_HOME/asciidart/config.yml* (*~/.config/asciidart/config.yml*), gives the default.
  An *-a asciidoctor-compat* option or the document's own attribute entry wins.

*ASCIIDART_JOBS_SHUFFLE*::
  When *1*, work done on other cores is handed back in a random order (for checking that the output doesn't depend on it).

*ASCIIDART_MANPAGE_PATH*::
  The file *-h manpage* prints instead of the built-in manual page (plain or gzip-compressed).

== Exit Status

*0*::
  The documents were converted (and no message reached the *--failure-level*).

*1*::
  Something failed: an invalid option, a missing or unreadable input file, a document that could not be converted, or a message at or above the *--failure-level*.
